# 答辩 QA（方向版）

> 用法：每题只记**方向**，现场用一两句话答；答不上就承认，再说思路。
> 数字记不住就说趋势，不要硬编。

## 通用

**Q：为什么不用 sklearn？**
A：作业要求手写算法；代码里只有 NumPy 做矩阵运算，建树、聚类、剪枝都在 `algorithms/`。

**Q：聚类没有标签，怎么评价？**
A：内部指标看 SSE、轮廓系数；外部指标 ARI 只拿真实品种做事后评估，不参与聚类。

**Q：为什么要标准化？**
A：量纲不同会主导距离（老师讲的身高/体重例子）；Z-score 后每个特征等权。

**Q：结果能复现吗？**
A：所有随机性由 seed 派生，同一种子逐位一致；20 个种子是为了看波动。

**Q：PCA 会不会改变聚类结果？**
A：不会。聚类、距离、SSE 都在完整特征空间算，PCA 只负责画二维图。

**Q：前端和 Python 怎么通信？**
A：pywebview 一个 API 对象；Python 算完返回 JSON，前端只播放记录好的帧。

## 标准 K-Means

**Q：K 怎么选？**
A：老师讲的手肘法——扫 K 看 SSE 拐点；再结合轮廓系数。我们扫了 K=1–8。

**Q：为什么初始化敏感？**
A：目标非凸，不同起点会落到不同的局部最优；所以有 K-Means++ 和多种子比较。

**Q：空簇怎么处理？**
A：中心没分到点时，从还有余量的簇里拿一个离自己中心最远的点补过去。

**Q：老师说的“空类错”是什么？**
A：初始中心选到很偏的点，形成只有一两个点的小簇，怎么迭代都拉不回来；靠 K-Means++ / 多种子避免，离群点可删。

**Q：K-Means 是全局最优吗？**
A：严格说是 SSE 的局部最优，受初始化影响；但它每轮所有点都能重新分配，二分劈开就回不去。

**Q：SSE 一定下降吗？**
A：分配和更新两步都不增，所以单调不增；状态有限，必然停在不动点。

**Q：复杂度？**
A：O(n·K·d·迭代)，就是老师课上的 n×k×i×d。

**Q：终止条件？**
A：位移 ≤ tol、分配不再变化、达到 max_iter，三种命中一个就停。

## 二分 K-Means 与改进

**Q：二分和普通 K-Means 本质区别？**
A：二分是分裂式层次，劈开不可回头；普通 K-Means 每轮都能全局重分配。

**Q：为什么二分 SSE 更高？**
A：叶簇劈完就固定，不再参与全局重分配；换来的是分裂树和可解释的过程。

**Q：为什么选 SSE 最大的簇，而不是样本数最多？**
A：SSE 直接对应目标函数；样本多但很紧的簇未必值得劈。两种都是启发式。

**Q：三项改进各解决什么？**
A：A 把起点选好；B 降低初始化随机性；C 把“选哪个簇”的依据从代理指标换成真实增益。

**Q：为什么 K=3 时 B1 和 B2 一样？**
A：候选太少，选簇策略没有差别；K=8 才看到 B2 低 2 左右。

**Q：为什么改进后 ARI 反而降？**
A：SSE 和真实类别不是一回事；改进买的是 SSE 和稳定，ARI 略降如实报告。

**Q：代价是什么？**
A：多次重启约 3 倍时间；B2 在 K=8 评估 28 个候选，B1 只评估 7 个。

**Q：消融怎么做的？**
A：B0 / B0++ / B1 / B2 每次只放开一个变量，20 个种子同种子配对比较。

## DBSCAN

**Q：eps 和 min_samples 怎么定？**
A：看 k-距离曲线的拐点；或者扫几个 eps 看簇数和噪声比例。我们扫了 0.8 / 1.0 / 1.2。

**Q：核心点怎么判定？**
A：eps 邻域内（含自己）至少 min_samples 个点；代码里就是数距离矩阵的一行。

**Q：密度直达、可达、相连？**
A：邻居与核心点直达；通过一串核心点传过去是可达；同属一个核心点邻域的两个边界点相连。

**Q：为什么噪声这么多？**
A：7 维标准化空间比较稀疏，eps=0.8 偏小；调大又会把簇连起来，这是取舍。

**Q：ARI 为什么低？**
A：28% 是噪声，而且密度簇不等于品种；ARI 把噪声当独立标签，惩罚很重。

**Q：高维为什么不好用？**
A：维度一高，点与点距离都差不多，eps 很难选。

**Q：复杂度和优化？**
A：这里直接算 n×n 距离，O(n²·d)；大数据要换 KD-tree / 球树。

**Q：和 K-Means 的区别？**
A：不用 K、允许噪声、形状任意；但对参数和密度分布更敏感。

## 层次聚类

**Q：两个方向？**
A：由总到分的分裂式（二分 K-Means 就是例子）和由分到总的凝聚式（我们做的）。

**Q：三种 linkage 区别？**
A：单链 min、全链 max、平均链 average；单链怕噪声，全链容易劈大类，平均链折中、更像全链。

**Q：K 怎么定？**
A：看树高的跳变或轮廓系数；也可以不切，用整棵树看层次结构。

**Q：为什么 O(n³)？**
A：每轮找最近两簇 O(n²)，共 n 轮；空间 O(n²)，要维护临近度矩阵。

**Q：合并能撤销吗？**
A：不能，所以层次聚类也是局部最优。

**Q：Ward 方法呢？**
A：没实现；代码里是 single / average / complete 三种，Ward 是最小方差准则。

**Q：树状图怎么读？**
A：纵轴是合并距离，越高越晚合并；横着切一刀，穿过几条竖线就是几个簇。

## CART

**Q：为什么用 Gini 不用信息增益？**
A：不用算 log，多分类直接算；CART 本来就用 Gini。

**Q：阈值怎么来的？**
A：每个特征排序，取相邻两个不同取值的中点；相同值之间不能切。

**Q：为什么剪枝用验证集？**
A：测试集只在最后看一次，否则评估有偏。

**Q：α 怎么选？**
A：对每个内部节点算弱链接系数，逐轮剪最小的，得到 α 序列；验证集选准确率最高，平局取叶少。

**Q：剪枝后训练准确率降了，为什么还说好？**
A：训练 .989 → .967，但测试 .933 → .967；换更小的树和更稳的泛化。

**Q：混淆矩阵怎么算指标？**
A：准确率 29/30；每类精确率/召回率，再算宏平均。

**Q：过拟合怎么看？**
A：不限深度长到底，训练 1.000，但测试只有 .933。

**Q：CART 和前面聚类的关系？**
A：CART 是有监督分类，聚类是无监督；评价方式和目标都不同。
