二分 K-Means 的三项自主改进

基线二分 K-Means 每轮只分裂“SSE 最大”的簇，且每次分裂只试一组初始中心。改进分别针对初始化敏感、单次分裂的局部最优、分裂顺序的贪心误差，代价是更多候选评估。

AK-Means++ 初始化

子簇的初始中心不再随机取点，而是按到已选中心距离平方加权采样，使初始中心彼此分散。

P(x) = D(x)² / Σ D(x)²

Wine：SSE 标准差 24.88 → 19.55；Seeds 平均迭代 11.55 → 10.20

B多次初始化择优

每个候选簇做 r 次 K=2 拟合（默认 5 次），保留 SSE 最低的一组，降低单次分裂的随机波动。

SSE* = mint=1..r SSE(K=2, seedt)

Seeds 454.43 → 448.93；Wine 1342.48 → 1329.28

C全局 SSE 降幅选簇

不再只挑 SSE 最大的簇，而是对所有可分裂簇试算一次分裂，选整体目标下降最多者。

ΔJ = J(C) − [ J(C₁) + J(C₂) ]

K=8：Seeds 262.46 → 260.37；Wine 980.27 → 976.90

代价与边界

改进不是无条件的
  • B2 在 K=3 时与 B1 结果相同，却多评估候选、耗时更高；收益只在 K 较大时出现。
  • 多次重启降低 SSE，但 ARI 可能下降（Seeds .7479 → .7419）：目标函数与真实标签并不完全一致。
  • 候选评估次数随 K 增长：K=8 时 B2 评估 28 次，B1 仅 7 次。
  • 所有随机过程由种子派生，同种子逐位复现，便于报告与答辩核对。
